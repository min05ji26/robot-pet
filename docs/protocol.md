# 통신 규칙 표 (v1.0 확정)

> 바꿀 때는 반드시 HW·SW 둘이 합의하고 버전을 올린다.
> 아두이노 코드의 값은 `firmware/` 안의 `protocol.h`와 항상 같아야 한다.

## 1. 패킷 형식

6바이트 고정 길이: `[STX 0x02][CMD][D1][D2][체크섬][ETX 0x03]`

| 필드 | 값 | 설명 |
|---|---|---|
| STX | `0x02` | 패킷 시작 |
| CMD | `0x01~0x07`, `0x81~0x86` | 명령코드 |
| D1, D2 | 0~255 | 데이터 (모든 값은 1바이트) |
| 체크섬 | `(CMD + D1 + D2) & 0xFF` | 합의 하위 8비트 |
| ETX | `0x03` | 패킷 끝 |

- 통신 속도: **9600bps** (HC-05 기본값)
- 수신 규칙: STX 찾기 → 6바이트 읽기 → **ETX이고 체크섬도 맞을 때만 인정**. 틀리면 버리고 다시 STX 찾기 (데이터에 0x02/0x03이 섞일 수 있음)
- 예: 서보 0번을 90도로 → `02 02 00 5A 5C 03`

## 2. LabVIEW → 아두이노

| CMD | 의미 | D1 | D2 |
|---|---|---|---|
| `0x01` | 상태 변경 (표정도 같은 번호로 함께 바뀜) | 상태 번호(0~5) | 0 |
| `0x02` | 서보 각도 | 채널(0~2) | 각도(0~180) |
| `0x03` | 멜로디 재생 | 멜로디 번호 | 0 |
| `0x04` | 박수 임계값 | 값 ÷ 4 (0~255) | 0 |
| `0x05` | 표정 출력 (테스트·연출용) | 표정 번호(0~5) | 0 |
| `0x06` | 모터 구동 | 0 정지 / 1 전진 / 2 후진 / 3 좌회전 / 4 우회전 | 속도(0~255) |
| `0x07` | 하트비트 | 0 | 0 |

- 하트비트는 **200~300ms마다** 보낸다. 아두이노는 1초 넘게 못 받으면 모터를 멈추고 `0x86`(원인 2 통신 끊김)을 보낸다.

## 3. 아두이노 → LabVIEW

| CMD | 의미 | D1 | D2 |
|---|---|---|---|
| `0x81` | 박수 발생 | 소리 크기 ÷ 4 | 0 |
| `0x82` | 장애물 거리 | 거리(cm, 최대 255) | 0 |
| `0x83` | 배터리 전압 | 전압 × 10 (예: 74 = 7.4V) | 0 |
| `0x84` | 동작 완료 | 완료한 CMD | 0 |
| `0x85` | 수신 오류 | 원인(1 체크섬 / 2 ETX 없음 / 3 모르는 CMD) | 0 |
| `0x86` | 안전 정지 | 원인(1 근접 / 2 통신 끊김 / 3 저전압) | 0 |

- `0x84` 동작 완료: `0x07`(하트비트)에는 보내지 않음 / `0x03`(멜로디)은 재생이 끝났을 때 보냄
- `0x86` 안전 정지 후: `0x06`(모터) 명령은 무시하다가, `0x01`로 대기(0) 또는 복귀(5)를 받으면 풀림. 단, 저전압(원인 3)은 풀리지 않음

## 4. 상태 번호 (FSM)

표정 번호도 상태 번호와 같게 맞춘다.

| 번호 | 상태 |
|---|---|
| 0 | 대기 (감은 눈) |
| 1 | 트리거감지 |
| 2 | 반응 |
| 3 | 탐색이동 |
| 4 | 회피 |
| 5 | 복귀 |

## 5. 거리·전압 기준

| 항목 | 값 | 판단 주체 |
|---|---|---|
| 회피 시작 | 20cm 이하 | LabVIEW |
| 즉시 정지 | 10cm 이하 | 아두이노 (LabVIEW 판단 없이) |
| 저전압 정지 | 6.6V 이하 | 아두이노 |
| 통신 끊김 정지 | 하트비트 1초 이상 끊김 | 아두이노 |
